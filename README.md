# TellTunes plugin repository

Play songs people send you by `/tell` in Final Fantasy XIV: YouTube, Spotify and playlists.

## Install
1. In game, open `/xlsettings` -> **Experimental**.
2. Under **Custom Plugin Repositories**, paste this URL, click **+**, then **Save and Close**:

   `https://raw.githubusercontent.com/Clair-songs/TellTunes-plugins/main/pluginmaster.json`

3. Open `/xlplugins`, search for **TellTunes** and click **Install**.
4. Type `/telltunes` to open it. People can then send you songs with `/tell <you> !q <link>`.

Updates arrive through `/xlplugins` like any other plugin.

TellTunes downloads yt-dlp the first time it runs. Sharing songs with other players is optional and needs
Penumbra and Lightless Sync (and Soundy with the Mega Music Mod for the SoundyQ setup).
